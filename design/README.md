# Design

This directory contains the user-centred design work for FoodSave Smart.

## Planned deliverables
- Research into student and canteen staff needs.
- Personas and user journeys.
- Wireframes and a shared Penpot prototype.
- Design guidelines covering colours, typography and components.
- Usability test plans, findings and recommended improvements.

## Core screens
- Student food catalogue.
- Food batch details and reservation.
- Student reservation list.
- Staff batch creation form.
- Staff collection confirmation.
- Temperature monitoring dashboard.
- Alerts and reports.

## Collaboration
Agree screen layouts and required data with the frontend and backend developers.

Record the shared Penpot link here when available.

Discuss changes affecting user journeys or API requirements with the relevant team members.

## Accessibility and usability
- Use clear labels and meaningful error messages.
- Provide readable text and sufficient colour contrast.
- Support keyboard navigation.
- Design for mobile and desktop.
- Test core tasks with users and document the findings.

## Evidence
Keep dated design versions and genuine research and testing records.

Obtain participant consent and remove identifying information from shared evidence.

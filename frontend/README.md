# Frontend

This directory contains the HTML, CSS and JavaScript files for the FoodSave Smart website.

## Planned features
- Student catalogue showing available food batches, allergens, prices and collection deadlines.
- Forms for staff to create food batches.
- Student reservation and cancellation controls.
- Staff controls to confirm collection.
- Temperature monitoring dashboard.
- Alerts and collection-based reports.
- Responsive layouts for mobile and desktop.

## Integration
The frontend communicates with the Flask backend through the agreed API.

Prices, stock availability and reservation rules are controlled by the backend.

Device tokens must never be included in frontend code.

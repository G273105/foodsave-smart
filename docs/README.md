# Documentation

This directory contains the shared project documentation for FoodSave Smart.

## Planned documents
- Common Technical Agreement.
- API contract and JSON examples.
- Database specification and data dictionary.
- System architecture and integration guide.
- Product backlog, sprint plans, Gantt chart and milestones.
- Meeting records and agreed decisions.
- Test plans, results and defect records.
- Setup and demonstration instructions.

## Meeting records
Record the date, participants, progress, blockers, decisions and agreed actions.

Each action should identify its owner and target date.

Keep genuine records of meetings and collaboration.

## Technical agreements
Clearly label documents as draft or approved.

Record the version, date and outstanding decisions.

Discuss changes affecting other components with the relevant owners before implementation.

## Evidence
Link requirements and tasks to relevant Issues, pull requests and test results.

Only describe work as completed or verified when supporting evidence is available.

## Repository rules
Write project documentation in British English.

Do not include passwords, device tokens or unnecessary personal information.

Each team member remains responsible for their individual portfolio and academic article.

## Status
Initial documentation is being prepared. Technical agreements remain subject to team approval.
